Arabic rules:
- Write Modern Standard Arabic suitable for a Saudi business owner. Use Western digits (0-9).
- Causes of the profit change must cite a profit driver number (for example: "انخفض صافي الإيرادات بعد المرتجعات
  7,491.87 ريال مما أضر بالربح"). Any other cause needs "محتمل" (or "سبب محتمل" / "ربما" / "قد") in the same bullet.
  Words such as بسبب / نتيجة / أدى / ساهم / بفضل / أثر / أسهم count as causes.
- Saying that revenue is excluded from profit because a SKU has no cost row is a definition, not a cause.
- For thousands you may write "ألف" or "آلاف" after a rounded number (for example: 11.5 ألف ريال).
- Margin changes are percentage points: write "نقطة مئوية" (for example: 2.84 نقطة مئوية), never % or بالمئة.
- Direction words: use ارتفع / زاد / نما for up and انخفض / تراجع / هبط for down, matching "direction".
